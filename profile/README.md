# Dispergo

Lightweight live media server. Single Go binary, runs as origin or edge.

Dispergo takes SRT/MPEG-TS contribution, normalizes it into one internal stream model, and serves HLS, durable local recording, and low-latency LL-HLS from the edge.

**[dispergo.net](https://dispergo.net/) : what it is, what it does, and why.**

The website is the place to read about the product. This organization exists for the parts GitHub does better: talking to us, and tracking what is broken.

## Status

Dispergo is in **private alpha**. The source repository is private.
